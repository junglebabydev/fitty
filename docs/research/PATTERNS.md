# Research — patterns adopted (condensed from three research passes, Sept 2026)

## Fitness / recovery (Whoop, Oura, Hevy, Strong, Fitbod, Runna, Gentler Streak, Athlytic, Apple)
1. Hero decision with 2–3 tappable reasons (Whoop dials, Oura "One Big Thing"); three-tier disclosure card → trend → raw.
2. Prefilled set rows with a PREVIOUS column; tap ✓ commits and starts an inline/sticky rest timer with ±15 s (Hevy/Strong). Compute timers from timestamps.
3. Live PR badge on commit; finish summary with volume, duration, PRs.
4. RIR as one-tap chips 0–4; set-type cycling by tapping the set number (W/D/F) is optional.
5. Pain-aware swap sheet that shows the reason for each alternative (Fitbod-style, filtered by knee/back/neck flags).
6. Week as a bucket of prioritised sessions; distinct Skip vs Move (Runna: "Skipping a run isn't a failure of discipline"); status modes (sick/injured/travel) pause expectations (Gentler Streak).
7. Baseline-band charts: shaded personal range + rolling average over faint raw dots, segmented W/M/6M, interpreted headline sentence above every chart (Apple WWDC22).
8. Visual: one huge tabular numeral per card, 11px uppercase tracked labels, a single accent, status colours reserved for status, hairline borders not shadows, spring motion on rings. iOS Safari has no vibration API — use motion/sound.
9. Anti-patterns: blank first-run dashboards and unexplained scores (Bevel), small fonts and too many screens (Caliber).

## Nutrition (MacroFactor, Cal AI, Foodnoms, Cronometer, MyFitnessPal, SnapCalorie, Carbon, Ate)
1. Hero block: calories and protein as equal bars; carbs/fat as small numerals; Consumed/Remaining toggle.
2. Time-stamped meal cards, no empty meal buckets (critical for 1–2 meals/day); photo thumbnail + kcal + protein; 7-day context strip with today boxed.
3. AI "Plate": editable item cards, keep adding missed items, sticky kcal/protein total + Log; AI framed as a speedy collaborator. Optional text/voice context with the photo.
4. Portion chips 0.5× / 1× / 1.5× / 2× with a grams field; macros recompute live.
5. Re-log fast: recents/favourites with preset portions, copy meal to today, time-of-day go-tos. Targets: repeat meal 2 taps, photo 3, voice 3.
6. Adherence-neutral: no red numbers, no warnings, no good/bad labels; over-target = same hue, bolder target tick, "+N". "Fasting day?" prompt for unlogged days.
7. Trend weight: bold smoothed line over faint scale dots, 14/30/90 chips; weekly check-in card "trend → intake → new target" with Accept / Keep current and a history.
8. Protein per meal vs daily target; weekly averages rather than streaks.

## Mind / holistic / coach (Apple State of Mind, How We Feel, Daylio, Headspace, Calm, Finch, Stoic, Bearable, Oura Advisor, Whoop Coach)
1. < 20 s check-in: 7-stop valence slider (save enabled on first touch) → optional feeling chips filtered by valence → optional context chips pre-filled from app data.
2. Breathing orb driven by a phase table; presets box 4-4-4-4, 4-7-8 (cap 4 cycles), physiological sigh, coherent 5.5; quiet completion with before/after mood delta; weekly mindful minutes, no streaks.
3. One-prompt journal (gratitude / win / reflection / reframe as a "thinking tool"), lock cue "Stays on this device", excluded from the AI coach.
4. Correlation cards gated by sample size (≥ 5 with and ≥ 5 without), show both averages and n, "tends to" wording, caveat about other factors.
5. Coach UI: suggested prompt chips, evidence chips, proposal cards with Accept / Keep current where declining has no side effects; "can make mistakes" notice.
6. Safety: non-clinical language; hard-coded offline Support sheet in ≤ 2 taps (mindline 1771, SOS 1767, SOS CareText WhatsApp 9151 1767, 995). The IMH 6389 2222 helpline was retired in 2025 — do not list it. No confetti on low mood, no urgency notifications, forgiving cycles.
7. Calm visual language: muted low-chroma hues, slow decelerating motion (500–800 ms) only where it serves the exercise; one type scale/radius/spacing system shared with the training areas; Today stays neutral.
